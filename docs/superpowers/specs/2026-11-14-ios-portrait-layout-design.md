# 暗房：手机上的竖屏构图

**Date:** 2026-11-14 (Asia/Shanghai)  
**Status:** approved (user confirmed 2026-11-14, Asia/Shanghai)

## 目标

手机上每一幕都铺满屏幕，字能读，要按的地方手指点得到。物件、光、颗粒、遮罩和三维跟电脑上是同一套，只改构图和机位。桌面宽屏继续用现在的 1600×1000 横画面。

不另做一批扁平页面。不换模型、材质、灯光和色调。不提高 WebGL 像素比。手机上仍然一次只装一幕。

## 何时切换

每一幕现在都把 `#stage`（1600×1000）按 `min(宽/1600, 高/1000)` 缩小后居中。这个倍率记为 `k`。

量宽高时，用 `innerWidth` 和 `visualViewport.width` 里较小的那个，高也一样。这样浏览器把布局视口报得比可见区域大时，仍按看见的那一块来排。

- `k < 0.7` 且高 ≥ 宽：竖构图。舞台改为铺满可见区域，`transform` 取消，`#stage` 加上 `portrait`，去掉 `phonewide`。
- `k < 0.7` 且宽 > 高：手机横放。`#stage` 加上 `phonewide`，去掉 `portrait`。仍取消缩小居中，放映格按 cover 铺满屏幕，中心对齐。物件保持桌面那套左右关系。热区至少 44×44 像素。信和清单的正文至少 16px，靠放大纸面达到，桌边可以裁进暗部。
- `k ≥ 0.7`：维持现在的缩小居中，两个类都不加。桌面和 iPad 横屏落在这里。

窗口尺寸或方向一变就重算，包括 `visualViewport` 的 resize 和 scroll。回到 `k ≥ 0.7` 时去掉 `portrait` 和 `phonewide`，三维画布和相机立刻回到 1040×694、宽高比 1040/694，以及各自现在的机位。

`roll-link.js` 里的 `ROLL.compact(w, h)` 只回答 `k < 0.7`。高和宽再决定类名：高 ≥ 宽加 `portrait`，宽 > 高加 `phonewide`。九幕的 `fit` 都走这里。测试直接跑 `ROLL.compact`：390×844、390×664、844×390、820×1180 为真；1440×900、1180×820 为假。844×390 为真，类名是 `phonewide`。

## 竖构图怎么留住视效

`portrait` 时舞台就是屏幕。放映格 `.proj` 仍是现在这一层：抖动、漏光、颗粒、模糊遮罩、暗角都还在，贴着舞台四边留 12px。遮罩继续用现在的圆角片门，拉伸到这个高格子上。

格子里的物件是原来的节点，改位置和字号。不平行再画一套。正文 17px。歌名 22px，仍是 Fraunces 斜体。片头标题在 40px 和 64px 之间，按格子宽度收成两行。手写红字 30px，热区至少 44×44。角标 12px。颜色仍是奶油色 `#f3e6d2`、墨色 `#040302`、红 `#ee5546`。

一屏一个主体，四周留暗。底部操作条只出现在留言和清单，用现在的细字，高度 44px，坐在纸下方的暗处，不盖住正文。

## 三维

胶卷、看片台、书继续用现在的渲染器：抗锯齿、软阴影、sRGB、ACES、现在的曝光、现在的环境和灯光。像素比仍是 `ROLL.pr()`（流畅 1、标准 1.5、清晰 2）。`setSize` 改成竖屏放映格的 CSS 像素，`camera.aspect` 改为该格子的宽/高，然后 `updateProjectionMatrix`。换画质或旋转时走同一条。

不新增 WebGL 上下文，不在片头预拉 three.js。片头那一层滤镜保持只有片头自己。

### 胶卷

四只罐子还是现在的网格、标签和玩法（拖出、举到灯前、看片器、印样）。桌面的木纹和台灯不动。竖屏只改罐子在桌面上的位置，收成一条浅弧，避免左右被裁掉：

| 卷 | 现在的 pos [x, z] | 竖屏 pos [x, z] |
|----|-------------------|-----------------|
| 1 | [-2.5, -0.35] | [0.15, -1.6] |
| 2 | [-0.75, 0.95] | [-0.2, -0.45] |
| 3 | [1.05, -0.75] | [0.2, 0.7] |
| 4 | [2.75, 0.7] | [-0.1, 1.85] |

相机的桌面机位保持 `(0, 7, 5.4)`，看向 `(0, 0, 0.15)`，垂直视角 32°。若有罐子出画，只沿现在的视线把相机拉远，直到四只罐子和靠近镜头的桌沿都在画内。玩法里的镜头运动仍从这台竖屏相机出发。

### 看片台

盘子、药水、安全灯和房间反光不动。相机保持现在的位置和看点（含 `?lt` 那组）。竖屏的水平视角变窄，桌子两侧可以出画，盘子留在画面中部。盘子边缘出画时，沿视线把相机拉远，直到盘沿完整，四周留一圈桌面。

### 书

书的网格、封面贴图、绒毛、台灯和咖啡馆环境光不动。竖屏把看点移到书 `(1.15, 0, -0.1)`，沿视线调整距离，使封面宽度约为格子宽度的 72%。旁边的信纸和笔还在场景里，可以落在暗处，灯仍照着它们。

## 九幕

幕序不变：片头、收音机、留言、清单、胶卷、看片台、漫画、书、片尾。口令弹窗仍是现在盖在片头上的那一层，不改它的字号和位置。片头 iframe 在竖屏里自己变成竖构图。

### 片头

光格铺满。标题和「宝宝，往下看」放在光里，红圈还在。右侧胶片条继续往下走，用现在的画面，不换成色块。角上的名字和天数留在暗处，12px。

### 收音机

同一间屋子、同一只灯泡、同一台收音机、同一根拉绳。灯在上方，收音机在中下，拉绳在机身右侧，珠子的可点范围至少 44×44。歌名在机身下，22px。换曲和打招呼的逻辑不变，包括沙沙声、英文问候和三首曲目。

### 留言和清单

木桌、纸纹、灯和撕开的动作保留。纸在光圈里长成一列，左右边距 16px，正文 17px，标题约 32px。纸的底边停在操作条之上。操作条仍是上一篇、下一篇、新的一篇、撕掉、下一幕，每项高度 44px。未改动的已有来源不拦翻页，这条现有规则保持。

### 漫画

粗墨线、套色和桌面的暗角保留。物件改成从上到下排进同一张桌子，点按翻面的玩法不变。不把它们换成照片列表。

### 片尾

和片头同一套光、颗粒和遮罩。字幕竖着滚，正文字号至少 18px。

## 测试

- `ROLL.compact` 的视口表，见上文。
- 1440×900 下片头舞台仍是缩小居中，没有 `portrait`，也没有 `phonewide`。
- 390×844 下片头放映格的可见高度大于屏幕的 70%，「宝宝，往下看」的字号至少 24px，热区至少 44×44。
- 390×844 下收音机歌名至少 20px，拉绳热区至少 44×44。
- 390×844 下留言正文至少 16px，五行按钮都在可见区域内，纸面不被条挡住。
- 竖屏胶卷的四只罐子投影都在画布内。看片台的盘沿在画布内。书封面宽度在格子宽度的 65% 到 80% 之间。
- 从 390×844 改到 1440×900，`portrait` 去掉，三维画布回到 1040×694，胶卷罐子回到原来的四个 pos。

用现有的页面测试和一次 iPhone 尺寸的浏览器测量完成上面几条。桌面路径跑现有胶片测试，确认没有改口令、问候语和歌单。
