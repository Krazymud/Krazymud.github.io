# 青庐蓝铅笔疾驰背景设计

日期：2026-10-14  
状态：设计已确认；实现计划已就绪  
基线：master 上已合并的青庐 polish + 品牌第一屏（PR #39 / #40）

## 1. 目标与非目标

### 目标

将全站背景从「暖纸石墨静景翻灯」换为**蓝铅笔可动漫画：开灯 RX-7 FC 东京街头疾驰循环**，并全站切换「夜稿」皮肤。

1. **8–12s 无缝循环**：直线 → 右入弯 → 漂移 → 侧面绕镜过渡 → 出弯加速 → 接环；车灯全程开启。  
2. **画风**：蓝/靛线稿、排线/涂鸦式局部上色、速度线、浅纸底、轻微胶片噪点——风格锚定用户提供的蓝铅笔可动漫画参考（Aleph 篮球广告片），**题材不复制**。  
3. **全站夜稿 UI**（首页 / 日课 / 锦匣 / 案头）。  
4. **路由表现**：非首页短淡出到静帧；回首页静帧短淡入后再播循环。  
5. `prefers-reduced-motion: reduce` → 仅静帧。

### 非目标

- 不嵌入参考广告原片、商标、篮球题材或角色。  
- 不回 3D；不改日课算法、锦匣加密同步、进度语义。  
- 不做紫霓虹 / 大面积黑底仪表盘 / 英雄贴纸角标。  
- 本设计不交付最终循环成片文件；成片在实现计划中按已批关键帧烘焙。

### 成功标准

- 去掉顶栏后，第一屏仍是「青庐」品牌 + 蓝铅笔疾驰 FC。  
- 进入日课/锦匣后背景为静帧，不持续抢戏。  
- 循环接环（末→首）无明显跳变。  
- 夜稿下正文与玻璃可读。

## 2. 已确认决策摘要

| 项 | 选择 |
|----|------|
| 画风 | 蓝铅笔可动漫画（非赛璐璐动漫） |
| UI | 全站夜稿（非「仅首页夜稿、内页暖纸」） |
| 非首页背景 | ≤300ms 淡出到静帧 |
| 回首页 | 静帧 ≤300ms 淡入 → 开播循环 |
| 环长 | 8–12s 完整体 |
| 镜头连续性 | 中间允许绕镜；**K1 ≈ K5** 锁死接环 |
| 入弯方向 | **车头向右入弯** |
| 分镜锚点 | 见 §4；K3b/K4 采用第一版（非后续加过渡的重绘版） |

## 3. 舞台与媒体行为

| 状态 | 表现 |
|------|------|
| 首页且可动 | 播放 drive 循环（优先 `webm` / `mp4`；体积过大则降分辨率或压缩） |
| 非首页 | ≤300ms 淡出到静帧（建议 K1/接环构图，车灯开） |
| 回首页 | 静帧 ≤300ms 淡入 → 从环起点播放 |
| reduced-motion | 永不播循环，只用静帧 |
| 加载失败 | 静帧兜底，不挡 UI |

### 资产约定（实现时落地）

| 文件（建议名） | 用途 |
|----------------|------|
| `public/sketch/fc-drive-loop.webm`（+ mp4 回退可选） | 首页循环 |
| `public/sketch/fc-drive-still.webp` | 静帧 / 非首页 / reduced-motion |
| 旧 `fc-loop.webp` / `fc-still.webp` | 成片验收后下线或仅作回退（实现计划定） |

### SketchStage

- 保持全屏 `fixed` 背景层。  
- 首页可叠极轻冷纸渐变保字可读；**不做**深色夜罩抢戏。  
- 无贴纸、无角标、无参考片水印。

### 镜头路径（锁定）

```
K1 直线 → K2 右入弯 → K3 漂移 → K3b 侧面绕转 → K4 出弯旋回 → K5 接环 ≈ K1
```

- 中间允许镜头绕车；首尾构图/朝向/开灯/比例对齐。  
- 烘焙成片时以表中文件为验收对照；偏离过大须重回关键帧对齐。  
- 车灯全程开启；不出现收灯/翻灯叙事。

## 5. 全站夜稿皮肤

| Token | 方向 |
|------|------|
| 底/纸感 | 冷白～浅灰蓝纸，非暖米黄 `#f1ebdd` 主路径 |
| 正文 | 近黑靛 / 深墨蓝 |
| 玻璃 | 更透的冷白玻璃；内页主栏略实仍偏冷 |
| 强调 | 墨蓝一线；不用红金车库 accent |
| 字体 | 站名可保留宋体栈；避免霓虹粗英文 |

### 壳层

- 首页：保持已上线的开敞英雄「青庐」+ 单日课 CTA；仪表仍在下方。  
- 内页：居中玻璃主栏结构保留，只换夜稿色。  
- 顶栏：略透冷玻璃，全站一致。

## 6. 成片生产（实现阶段）

1. 以 §4 关键帧为分镜，烘焙 8–12s 循环 + 静帧。  
2. 接环验收：末帧与首帧对齐。  
3. 接线 `SketchStage`、路由淡入淡出、夜稿 CSS token。  
4. 体积以移动端可接受为优先（必要时 720p）。  
5. 版权：只学风格，不使用参考片像素。

## 7. 测试与验收

### 自动化

- 首页可动时请求 drive loop；`data-motion` 区分 loop/still。  
- 非首页为静帧；不持续播循环。  
- reduced-motion → 仅静帧。  
- 路由切换存在短淡入淡出（或可测状态）。  
- 夜稿路径：主底不再以暖纸 `#f1ebdd` 为默认。  
- 日课 / 锦匣既有行为测试保持绿色。

### 手动

- 桌面 + 手机：循环与夜稿字可读；非首页不抢戏。  
- 接环 K5→K1 无明显跳。  
- 无参考广告商标 / 篮球题材残留。

## 8. 开放实现细节

- 循环容器：默认 `webm` + `mp4` 回退；若体积允许再评估动画 WebP。
