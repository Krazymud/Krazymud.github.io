# 青庐·纸窗统一设计

日期：2026-10-14  
状态：实现中（用户选定方向 A）

## 目标

把「暖纸 UI + 夜色漫画背景」拧回同一叙事：**青庐是纸窗前的案头，窗外是低饱和石墨 FC 素描**。

## 视觉原则

1. **纸窗**：暖纸底 `#f7f4ec`，浅液态玻璃一材质，墨色字与描边。
2. **窗外素描**：同一驱动成片，滤镜改为低饱和石墨线描（非赛璐璐上色、非土色水墨）。
3. **一构图**：首屏 = 站名「青庐」+ 一句问候 + 一句辅文 + 一个主 CTA；仪表下移。
4. **去车库残留**：去掉字距夸张眉题、霓虹 glow、方形仪表壳；nitro 闪仅保留极轻墨晕。

## 非目标

- 不改日课/锦匣业务逻辑。
- 不重下片源；沿用 `fc3s-ref-drive.mp4` 与开合时序。
- 不做方向 B（冷夜 UI）。

## 验收

- 去掉导航后，首屏仍能读出「青庐」。
- 背景与 UI 同为暖纸/石墨族，无霓虹色斑。
- 翻灯循环仍闭合；`npm test` 通过。
