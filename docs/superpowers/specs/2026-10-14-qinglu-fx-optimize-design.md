# 青庐视效优化设计

日期：2026-10-14  
状态：设计已确认（待实现计划）  
基线：master 回退后的青庐 polish（PR #31 / #39）——暖纸 + 石墨素描 WebP 舞台

## 1. 目标与非目标

### 目标

在**不重绘画风、不重做「纸窗统一」**的前提下，按优先级优化视效：

1. **P0 · 舞台与 UI（B）**：首页第一屏一眼是「青庐 + 车」，不是小仪表盘；玻璃更透但仍可读。
2. **P1 · 交互动效残留（C）**：清掉锦匣金库门、金属扫光、仪表车库口吻等与暖纸石墨不一致的残留。
3. **P2 · 素描呈现轻触（A）**：不换风格；最多改善裁切与循环观感。

### 非目标

- 不重绘 FC、不上视频/漫画、不回 3D。
- 不改日课算法、锦匣加密与同步、进度存档语义。
- 不做全站第二套主题或大换色板。
- 不做深色 vignette / 夜色罩、不在素描上叠加贴纸角标。
- 不新做音效包（沿用现有 tap/confirm/unseal）。

### 成功标准

- 去掉顶栏后，第一屏仍能认出是青庐（大号品牌 + 石墨车）。
- 仪表仍在首页，但不占第一屏主位。
- 锦匣开匣不再像银行金库门。
- 色板与字体栈（暖纸 ink、墨色 fg、Songti display、glass 语言）基本不动。
- `prefers-reduced-motion: reduce` 时素描仍为静帧，功能可用。

## 2. 诊断摘要（已确认优先级）

| 优先级 | 主题 | 结论 |
|--------|------|------|
| P0 | 舞台与 UI | 全屏素描被居中实色 `main` + 仪表/CTA 堆叠挡住；品牌只在顶栏。上一版「纸窗统一」动这块过头被否——本次只做克制构图。 |
| P1 | 交互动效 | `VaultDoor` / `GoldSweep` / Dashboard glow 与宽字距仍是车库 DNA；`nitro` 无视觉消费者。 |
| P2 | 素描舞台 | `fc-loop.webp`（6 帧）观感已认可；重绘风险最高，只做呈现层。 |

落地路径（已选）：**品牌第一屏（Approach B）**——第一屏品牌英雄级 + 轻透叠字；再清 P1；P2 轻触。

## 3. 首页第一屏（P0）

### 结构

第一屏（约一屏高）只包含：

1. 顶栏（略透玻璃，站名可保留）
2. **英雄级「青庐」**（主视觉文案，压过问候）
3. 一句问候：`{nickname}，安`（第一屏不显示「又见」，避免压品牌）
4. 可选：相伴第 N 天（一行，次级）
5. **一个**主 CTA：今日日课（轻玻璃按钮，文案如「今日日课 · 出发」）

滚动后（非第一屏）：Dashboard（连续 / 本周 / 掌握）、锦匣次入口、既有进度信息。

### 壳层

- **仅路由 `/`**：开敞首页——无实色 `main` 盒包住第一屏；文案叠在素描上；底部暖纸色渐变（`#f1ebdd` 系）保证 CTA 区对比。
- **日课 / 锦匣 / 案头**：维持现有居中 `glass-panel` + `glass-panel-solid` 主栏（长文与表单可读优先）；素描仍在背后略透。
- 顶栏全站可略透一点；不换圆角语言、不加新装饰层。

### 禁止

- 全站改成石墨夜底或重做 glass「材质故事」。
- 第一屏放统计条、日程、多入口卡片堆。
- 在素描上叠浮动徽章/贴纸。

## 4. 玻璃与色板

- 色板保持：`--color-ink` / `--color-fg` / `--color-line` / `--font-display` 等现有 token。
- 首页叠字区：半透明白玻璃仅用于顶栏与 CTA；正文用墨色 + 暖纸渐变衬底，不靠大实色卡片。
- 内页 `glass-panel-solid` 不透明度不强制下调到伤害可读性。

## 5. 清车库残留（P1）

| 现状 | 调整 |
|------|------|
| `VaultDoor` 全屏保险库门 + 螺栓 | 改为轻量「启封」短淡入（≤400ms）；`prefers-reduced-motion` 时跳过，直接进入内容；不再全屏金属门 |
| `GoldSweep` 金属斜扫 | **删除**（不做金属/金色扫光替代） |
| Dashboard「青庐仪表」+ 宽字距 + 光点 glow | 保留数据与环；去掉 glow 与夸张 `tracking`；caption 保持「连续 / 本周 / 掌握」 |
| `emitNitro` 无消费者 | 不做新视觉消费；实现时可保留事件以免打坏日课测试，或一并收束并更新测试 |
| 日课 Gauge / 结算 | 保留功能动效；去掉夸张字距/车库口吻（若有） |

不改锦匣加密 UI 流程与日课规则，只换皮肤与开匣演出。

## 6. 素描呈现轻触（P2）

资产继续：`public/sketch/fc-still.webp`、`fc-loop.webp`（及既有 `fc-up.webp` 若采用交叉淡化）。

**可做**

- `object-position`：手机竖屏优先露出车头/翻灯。
- 若 6 帧循环偏硬：可选 still↔up CSS 交叉淡化，或微调 loop 帧时长；失败回退单张 animated loop。
- `prefers-reduced-motion: reduce` → 仅 still。

**不做**：视频/漫画/新板绘、夜色重上色、SVG 灯罩、复杂多帧构建流水线。

## 7. 组件与实现边界（计划阶段细化）

| 单元 | 职责 | 依赖 |
|------|------|------|
| `Layout` | 按路由选择「开敞首页壳」vs「内页玻璃主栏」；顶栏略透 | `sceneFor` / pathname |

| `Dashboard` | 去 glow / 宽字距 | stats 逻辑不变 |

不引入新 3D、不新增主题切换。

## 8. 测试与验收

### 自动化

- 首页主区存在英雄级「青庐」（非仅顶栏）。
- 第一屏容器内不出现仪表环 / 锦匣次入口（或断言它们在「下方」区块）。
- SketchStage：默认 loop；reduced-motion → still。
- 锦匣：无全屏 `vault-door` 金库门；无 `GoldSweep`。
- Dashboard：无 glow class；数字逻辑回归不变。
- 日课 / 锦匣读写与同步既有测试保持绿色。

### 手动

- 桌面 + 手机：第一屏品牌与车可读；CTA 对比足够。
- 内页长文与解锁表单：实色主栏清晰。
- 网络：无视频（mp4/webm）素描请求；无夜色罩/贴纸。

## 9. 开放实现细节

- 「又见」眉题：默认**不在第一屏显示**，以「青庐」为唯一英雄文案。
- 启封演出：默认短淡入（≤400ms）；reduced-motion 跳过。
- still↔up 交叉淡化：默认**不做**；先交付 object-position + 壳层/首页；仅当验收认为 loop 偏硬时再加。
