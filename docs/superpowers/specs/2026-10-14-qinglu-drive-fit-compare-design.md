# 青庐疾驰环：A 融边（细化）

日期：2026-10-14  
状态：选用 **A**，细化无硬边过渡  
基线：横版 Kling 环（不再使用竖版专用成片 / C 微裁）

## 决策

对照后选定 **A 融边**。要求上下过渡尽量看不出「嵌套视频」边。

## 实现

窄屏（`<sm`）：

1. **Ambience 层**：同一静帧 `object-cover` + 强模糊 + 略放大，铺满视口，填掉 contain 留白。  
2. **Sharp 层**：横版环 / 静帧 `object-contain`，整车完整。  
3. **轻噪**：极低透明度纸纹，统一纸感。  
4. **玻璃**：略更透，让素描透出来。

桌面 `sm+`：仅 sharp cover（与既有一致）；ambience / 噪点隐藏。

## 非目标

- 不再维护 `?sketchFit=c` 折中微裁。  
- 不出竖版专用成片。
