# Midnight Garage 1.2：车库升级设计

状态：待审

## 1. 目标

车库目前只有问候、试炼卡、保险库入口，3D 场景里只有反光地面、黑背景和看不见的灯光板，显得单薄。1.2 从三方面充实它：

1. 仪表盘条：把学习数据做成车库里的仪表。
2. 时间氛围：车库灯光随她本地时间缓慢变化。
3. 车库场景：地面材质、旋转展台、后墙与 LED 灯带、霓虹灯牌、道具剪影、光柱与尘埃。

不在本版：保险库开门动画与今日回忆（1.1）、车辆改装（1.3）、镜头构图调整、赛道与保险库场景的改动（地面材质除外）。

## 2. 仪表盘条

### 2.1 布局

在车与试炼卡之间加一排，结构「左圆表 · 中间七盏灯 · 右圆表」，宽度与试炼卡一致（`max-w-md` 容器内）。手机竖屏下三者仍在一行，圆表直径约 64 px。

| 位置 | 内容 | 外圈填充 |
|---|---|---|
| 左圆表 | 连续打卡天数，下方小字「连续」 | 按 7 天一圈：`streak % 7 / 7`，整 7 的倍数且大于 0 时满圈 |
| 中间 | 最近 7 天打卡灯，最右一盏是今天，下方小字「本周」 | — |
| 右圆表 | 掌握词数，下方小字「掌握」 | 到下一个整百的进度：`(mastered % 100) / 100` |

到期复习数并入试炼卡：`今日试炼` 标签行改为 `今日试炼 · 到期 N`（N 为 0 时只显示 `今日试炼`），原来单独一行「到期复习 N 个」删除。

### 2.2 数据规则

纯函数 `garageStats(data: ProgressData, today: string): GarageStats`，放在 `src/garage/stats.ts`。

- 打卡日：`data.history` 中出现的 `day`（学习日按现有凌晨 4 点分界，`history` 只在当天试炼完成时追加）。
- `streak`：若今天已打卡，从今天往前数连续打卡日；否则从昨天往前数。昨天也没打卡则为 0。
- `week`：长度 7 的布尔数组，下标 0 是 6 天前，下标 6 是今天。
- `todayDone`：今天是否已打卡。
- `mastered`：复用 `masteredCount(data.words)`。
- `due`：复用 `dueOn(data.words, today)`。

不改任何数据格式。

### 2.3 外观

- 圆表：细描边圆环，底环用 `--color-line`，填充弧用 `accent-hi`；中间大号 `font-display` 数字。
- 打卡灯：小圆点，已打卡为 `accent-hi` 实心并带轻微辉光；未打卡为 `line` 描边空心；今天未打卡时空心描边做呼吸动画（减少动态效果时不动）。
- 组件 `src/garage/Dashboard.tsx` 只负责显示，数据由 `HomePage` 传入。
- 无障碍：整条有可访问名「车库仪表」；每个圆表读作「连续打卡 N 天」「已掌握 N 个词」；七盏灯读作「最近 7 天打卡 K 天」。

## 3. 时间氛围

### 3.1 计算

纯函数 `ambienceAt(date: Date): Ambience`，放在 `src/scene/ambience.ts`，不引入 three。

```ts
interface Ambience {
  key: string        // 主灯颜色（hex）
  keyScale: number   // 主灯亮度系数
  env: number        // 环境光亮度系数
  strips: number     // LED 灯带与霓虹灯牌亮度系数
  tint: string       // 静帧叠色（rgba）
}
```

四个关键时刻（本地时间）及初值，做好后截图给用户再微调：

| 时刻 | key | keyScale | env | strips | tint |
|---|---|---|---|---|---|
| 02:00 深夜 | 现有 `#9E1C22` | 1 | 1 | 1 | `rgba(0,0,0,0)` |
| 07:00 清晨 | 暖橙 `#d2643a` | 1.35 | 1.5 | 0.55 | 暖橙 0.14 |
| 13:00 白天 | 暖白 `#e2b49c` | 1.7 | 2 | 0.3 | 中性白 0.16 |
| 19:00 傍晚 | 深橙 `#cc4a1c` | 1.3 | 1.3 | 0.8 | 琥珀 0.14 |

其余时间在相邻两个关键时刻之间线性插值（颜色在线性空间插值），跨午夜从 19:00 插到次日 02:00。深夜档就是现在线上的样子。

### 3.2 生效范围

- 只作用于 `garage` 与 `settings` 两个姿态（两者共用车库镜头）。赛道与保险库保持各自现有灯光；切换时沿用现有 1.2 秒阻尼过渡。
- 3D：`Stage` 每分钟取一次时间算出 `Ambience`，`Studio` 把主灯颜色、主灯亮度、环境光亮度阻尼跟随；点火开场的灯光等级仍乘在最外层。
- 静帧：车库静帧始终以深夜档渲染；静帧模式下在静帧上叠一层 `tint` 色（CSS，`mix-blend-mode: soft-light` 或等效），不重新生成多套静帧。
- 减少动态效果：直接使用当前时刻的值，不做过渡。
- 确定性渲染（生成静帧）固定使用 02:00 的值。

## 4. 车库场景

### 4.1 素材

- 地面：CC0 磨光水泥 / 环氧地坪材质（颜色、粗糙度、法线），来源 Poly Haven 或 ambientCG，具体条目在计划阶段选定并核实 CC0 许可。
- 后墙：CC0 竖条纹金属板材质（颜色、粗糙度、法线），同上。
- 处理：新增 `npm run textures`，从 `assets-src/textures/`（gitignored）读取原图，用 sharp 输出 1024×1024 WebP 到 `public/textures/`；颜色贴图 sRGB，其余线性。合计目标 ≤ 500 KB，单张 ≤ 150 KB，超限时报错。`.gitattributes` 加 `public/textures/** -text`。
- 设置页鸣谢补上两套材质的作者与链接。

### 4.2 元素

坐标以车为原点，车库镜头在车的左前方（`[-4.6, 2.3, 6.4]`，看向 `[0, -0.6, 0]`）。「后方」指沿镜头视线越过车的方向。

- **地面**：现有 `MeshReflectorMaterial` 加上水泥的颜色、粗糙度、法线贴图，平铺约 4 m 一格；三个场景通用。
- **旋转展台**：直径约 5 m、高约 6 cm 的深色拉丝金属圆盘，车停在上面并随车的转角一起转（车自转时展台同步，赛道/保险库固定朝向时展台也同朝向）。边缘一圈细灯带，颜色跟随姿态主色（车库暗红、保险库金）。展台在所有场景都在。
- **后墙**：面向车库镜头、位于车后方约 9 m 处的一面宽约 16 m、高约 6 m 的墙，贴金属板材质；墙上嵌 4 条竖向 LED 灯带（冷白自发光，亮度 × `strips`），借现有辉光晕开。
- **霓虹灯牌**：避开页面问候语——横屏在后墙左侧面板，竖屏在后墙下部居中（问候语与车之间），MIDNIGHT GARAGE，用 Rajdhani 字体（等字体加载完）画进 Canvas 贴图后作为自发光平面，颜色 `#C1272D`，亮度 × `strips`。
- **道具剪影**：后墙两侧各一组，一个工具柜（盒体组合）、一个轮胎架（几个圆环叠放），深色低细节，不投影。
- **光柱**：主灯下方三层嵌套的很淡的加色锥体（边缘逐层变淡），沿长度方向两端渐隐，颜色跟主灯。
- **尘埃**：约 150 个点精灵在车周围缓慢漂浮，颜色暖白、很淡。

### 4.3 显隐与过渡

- `Pose` 新增 `room: number`：`garage`、`settings` 为 1，`track`、`vault` 为 0。后墙、LED、灯牌、道具、光柱、尘埃统称「车库房间」，其不透明度 / 亮度按 `room` 阻尼跟随（沿用 `TRANSITION_LAMBDA`），低于阈值时 `visible = false`。
- 地面材质与展台不随 `room` 隐藏。
- 点火开场：LED、灯牌、光柱的亮度同样乘以点火灯光等级，开场时与整个车库一起闪亮。
- 画质：`FrameGuard` 降到画质档 2 时关闭光柱与尘埃。确定性渲染（生成静帧）时尘埃固定不动。减少动态效果时本来就只显示静帧，不涉及尘埃。

### 4.4 体积与性能

- 所有新 3D 代码都在 `src/scene/three/` 内，随 Stage 块按需加载；主包体积不变（仍须 ≤ 200 KB gzip，且不含 three）。
- 贴图走 `useTexture` 预加载，计入点火开场的加载进度。
- 车库静帧（横竖两张）重新生成；其余静帧若因地面材质变化也需重新生成；构图不变；单张仍 ≤ 120 KB。

## 5. 测试

- `garageStats`：空进度、今天已完成、今天未完成但昨天完成、断签、跨月、`week` 顺序。
- `Dashboard`：渲染数字与可访问名、今天未完成时有呼吸态、减少动态效果时无动画类。
- `HomePage`：试炼卡显示到期数、原单独一行已移除。
- `ambienceAt`：四个关键时刻精确值、两个关键时刻中点、跨午夜（如 23:00、01:00）、返回值有限。
- `npm run textures`：尺寸、格式、体积上限、临时文件清理（同 audio / stills 的测试方式）。
- 3D 组件不做单元测试，用控制器浏览器检查：四个时刻的截图（可在开发环境用查询参数覆盖时间，仅开发环境生效）、切到赛道和保险库时房间淡出、点火闪亮、低画质档关闭光柱和尘埃。

## 6. 风险

- 贴图加大首屏 3D 加载时间：控制在 500 KB 内并计入开场进度。
- 白天档太亮破坏「午夜」气质：初值保守，截图后再调。
- 手机性能：光柱、尘埃在低画质自动关闭；反射分辨率不变。
