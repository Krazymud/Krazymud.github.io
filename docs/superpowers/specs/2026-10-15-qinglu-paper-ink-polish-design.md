# 青庐纸墨抛光设计（视觉 B + 日课 C + 开图 P0）

日期：2026-10-15  
状态：待审阅  
基线：FC 双码率已告一段落的 master；方案 2（纸墨统一波）

## 1. 目标与非目标

### 目标

1. **B · 视觉统一与克制美化**：全站收成「青庐纸墨」语言（glass、描边、字距、日课动效去车库 DNA），并做少量美化动效。
2. **C · 日课易用**：手机上更好答、更好读；不改选词 / SRS / 进度语义。
3. **P0 · 锦匣开图**：点开即在当前视口全屏可见；顶底控件落在安全区内；支持双指缩放。

### 非目标

- 不动 FC 双码率管线；不迁 CDN；不改锦匣加密协议。
- 不重做日课题型算法；不做深色第二主题。
- 不做 3D、不做新音效包。
- 本波不回补锦匣冷开 / 清单修复（#49–#51）。

### 成功标准

- 日课不再出现「氮气 / 赛道扫线」视觉；改为纸墨轻反馈。
- 首页仪表、日课结算、锦匣面板共用同一套面板 / 按钮样式。
- 全站主字体为霞鹜文楷 + 日课英文 Source Serif 4；无 Inter/Roboto/车库科技体作为主界面字。
- 手机点开照片：视口内立刻看到图与关闭 / 翻页控件；可 pinch 缩放。
- `prefers-reduced-motion: reduce` 时功能完整、装饰动效可关。

## 2. 锦匣开图（P0）

### 问题

1. `PhotoViewer` 使用 `fixed inset-0`，但挂在带 `backdrop-filter` 的内页 `glass-panel` 主栏内；在 iOS 上 containing block 变为整页长文档，照片落在页面中部，需上下滑才看见。
2. 序号 /「关闭」与说明 / 日期 / 上一张·下一张分处文档顶底，拇指难够。

### 方案

1. **Portal 到 `document.body`**  
   - 真正相对视口全屏；打开时锁背景滚动（`overflow: hidden`），关闭后恢复。  
   - `PhotoGrid` 与 `MemoryCard` 共用同一 Viewer。

2. **视口内三层布局（手机优先）**  
   - **顶栏（safe-area）**：左 `index / total`，右大触控「关闭」（约 44px 高）。  
   - **中区**：照片 `object-contain` 占满剩余高度；左右滑切图保留。  
   - **底栏（safe-area）**：说明 + 日期；其下「上一张 | 下一张」并排大按钮。  
   - 顶/底栏半透明墨色条叠在图上，不把图挤出视口。

3. **双指缩放**  
   - Pinch 缩放；单指拖平移（缩放 >1 时）。  
   - 双击复位到 1×。  
   - 缩放 >1 时暂不抢左右滑切图；松手接近 1× 时恢复切图。  
   - 不做旋转；不持久化缩放状态。

4. **其他**  
   - 点遮罩非控件区域可关闭（默认开）。  
   - 桌面：← / → / Esc 不变。  
   - reduced-motion：无额外动画，布局与缩放仍可用。

### 非目标（开图）

分享、编辑、保存到相册。

## 3. 视觉系统（纸墨 token + 组件 + 字体）

### 色与材质（沿用并收束）

- 底：`--color-ink` 暖纸；字：`--color-fg` / `--color-muted`；线：`--color-line`
- 强调：墨色 `--accent` / `--accent-hi`（不用车库红金）
- Glass 三档：`nav`（顶栏更透）、`panel`（首页叠层）、`solid`（内页长文可读）
- 圆角：控件统一 `rounded-lg`；避免多阴影卡片堆

### 字体（全站艺术化统一）

| 角色 | 字体 | 说明 |
|------|------|------|
| 全站中文 / UI | **霞鹜文楷（LXGW WenKai）** | 主族；站名同族更大字号 + 略增字距 |
| 日课英文词头 | **Source Serif 4** | 书卷衬线，保证英文清晰 |
| 数字 | Source Serif 4 tabular（优先）或文楷数字 | 与拉丁同源 |

**加载**：自托管 `woff2` 于 `public/fonts/`；文楷裁切常用汉字+标点；Source Serif 4 仅 Latin+数字；`font-display: swap`；fallback 为系统宋/楷。

**不用**：Inter / Roboto / 纯 system-ui 作主界面；强书法网红体；Rajdhani 等旧车库科技体。

**可读性**：日课选项与锦匣长文文楷 ≥16px、行高约 1.6。  
**降级预案**（仅当真机正文过「花」）：正文改 Noto Serif SC，标题保留文楷——默认仍全文楷。

### 组件语言

| 角色 | 要点 |
|------|------|
| 主按钮 | 墨边 + 浅墨底，触控高 ≥44px |
| 次按钮 | 线框 + muted 字 |
| 面板 | `glass-panel` / `solid`，细白边，无金属扫光 |
| 进度环 / 条 | 细线墨色；无 glow |
| 日课选项 | 大触控行；对=墨底高亮，错=划线弱化 |

### 克制美化动效（2–3 处）

1. 内页进入：主栏轻微 opacity/translate（≤280ms），reduced-motion 跳过  
2. 日课连击：墨色呼吸或短印记，替代氮气/赛道线  
3. 首页英雄「青庐」：仅微调与素描叠字对比，不加贴纸/徽章  

### 删除 / 降级

- 赛道扫线 `TrackStreak`、氮气 `NitroFlash` 视觉（`emitNitro` 可留空或收束测试）
- 用户可见 `midnight-garage-*` 导出文件名 → `qinglu-progress-*`
- 「青庐仪表」aria → 更中性（如「学习进度」）

## 4. 日课易用（C）

### 原则

不改选词、SRS、每日 20 词、进度存档；只改信息层级、触控与反馈气质。

### 答题布局（手机优先）

1. **顶区**：进度（当前/总数）+ 连击——纸墨细环/细条；去掉转速表车库感。  
2. **中区**：题干（英文 Source Serif 4，中文文楷）+ 加大发音触控。  
3. **选项**：全宽、最小高度 ~48px、间距加大；对/错态见上表。  
4. **底区（主栏内 sticky + safe-area）**  
   - 答对：「还行 | 会了」两大按钮 + 倒计时细线（默认仍 ~5s 记「还行」）  
   - 答错：全宽「下一题」

### 反馈动效

- 停用 `TrackStreak` / `NitroFlash` 视觉。  
- 连击 5 / 10：短促纸墨反馈（≤400ms）。  
- reduced-motion：无装饰动效，流程不变。

### 结算页

- 统计格统一 panel + 文楷/衬线数字，去掉夸张字距。  
- 主 CTA「回青庐」用主按钮样式。  
- 顺序：完成眉题 → 用时/正确率 → 掌握与明天到期 → 回家。

### 文案

- 首页 CTA「出发」可保留。  
- 导出进度：`qinglu-progress-YYYY-MM-DD.json`。

### 非目标（日课）

新题型、手势划答、改每日词数、跨日策略。

## 5. 架构边界 · 测试 · 实现顺序

### 模块

| 单元 | 职责 | 不做什么 |
|------|------|----------|
| `theme/fonts` + `index.css` | 自托管字体、token、组件类 | 不改业务逻辑 |
| `PhotoViewer`（+ portal） | 视口全屏、顶底栏、pinch/pan、切图 | 不改加密/blob |
| `QuestionCard` / `GradeBar` / `Gauge` / `Effects` | 日课触控与纸墨反馈 | 不改 engine/SRS |
| `ResultPanel` / `Dashboard` / `Layout` | 统一面板按钮、去车库可见残留 | 不改进度语义 |
| `copy` + 导出文件名 | 青庐用语 | 不改路由 path |

### 测试

**自动化**

- Viewer：portal 到 `body`；Esc / 切图；关闭恢复滚动。  
- 日课：选项与评级流程回归。  
- 字体：CSS 变量 / family 存在。  
- 无 `TrackStreak` / `NitroFlash` 挂载（或等价）。  
- 导出文件名含 `qinglu-progress-`。  
- 既有 vault / trial 测试保持绿色。

**手动**

- 手机开图无需滚动；顶底栏在视口内；pinch 与滑切不打架。  
- 日课单手点选项 + 底栏评级。  
- 桌面首页/内页字体与对比度。

### 实现顺序

1. P0 开图（portal + 顶底栏 + pinch）  
2. 字体接入 + token / 按钮面板类  
3. 日课皮肤与底栏评级 + 去氮气/赛道视觉  
4. 仪表 / 结算 / 导出命名收尾  

### 本波明确不做

CDN 迁移、锦匣冷开/#49–#51 回补、FC 再编码、SRS 改规则。
