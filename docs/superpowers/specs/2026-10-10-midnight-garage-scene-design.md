# Midnight Garage · 3D 车库场景设计文档（计划 3A）

日期：2026-10-10
状态：已确认
上级文档：`docs/superpowers/specs/2026-10-09-midnight-garage-design.md` 第 3.3、6.2、6.3 节。本文细化并在冲突处取代这几节中与 3D 场景有关的内容。开场转速表动画和音效属于计划 3B，不在本文范围内。

## 1. 目标和完成标准

把现在的 SVG 剪影背景换成一辆可以转动的 3D 超跑，切换栏目时镜头和灯光平滑过渡。

1. 在手机上打开首页，先看到静帧，随后 3D 车库淡入；车缓慢自转，横向拖动可以转车。
2. 在车库、赛道试炼、保险库之间切换时，镜头和灯光约 1.2 秒平滑过渡，画布不重建。
3. 开启「减少动态效果」、浏览器不支持 WebGL 2、在设置里关掉 3D、或 3D 加载失败时，显示对应镜头的静帧，所有功能照常可用。
4. 主程序包（不含 3D 分包）压缩后不超过 200 KB；车模型不超过 3 MB。
5. 设置页的「鸣谢」里有车模型的 CC BY 署名。

**不做：** 开场转速表动画、音效和静音开关（计划 3B）；缩放或俯仰视角；开车门等部件动画；车漆配色切换。

## 2. 车模型

- 来源：Sketchfab 上 ollitei 的「Fictional supercar - V12 Goblin」，授权 CC BY 4.0。原页面：https://sketchfab.com/3d-models/fictional-supercar-v12-goblin-0a20e49ad5774d778567cb5c3f345786 。这是作者 2012 年原创的虚构车型，没有真实品牌的车标或名称。
- 原模型没有内饰，车窗统一使用深色不透明玻璃材质。
- 原始文件由用户登录 Sketchfab 后以 glTF 格式下载，解压到 `assets-src/car/`。`assets-src/` 写进 `.gitignore`，不提交。
- 原模型结构（已核实）：5 个 Spec-Gloss 旧格式材质（`car_tire`、`car_body`、`car_glass`、`clearcoat`、`car_shadow`）。车身、轮毂和卡钳共用 `car_body` 材质和一张 4096×2048 的贴图集，车身本身已经是黑色，漆面区域在高光贴图里是一块独立的颜色。四个车轮（`car_wheel_FL/FR/BL/BR`）和四个卡钳（`car_brake_*`）是独立节点，旋转中心在轮轴上。`clearcoat` 是一层叠在车身外的光泽壳（约 2 万面）。`car_shadow` 是一张烘焙好的地面阴影。约 8.7 万面，无动画。
- 重新上材质（按网格分配角色，因为车身、轮毂、卡钳共用同一个原材质）：

| 角色 | 网格 | 材质 |
|---|---|---|
| 车身 | `car_body_*` | 保留原贴图集的细节，转为标准金属度/粗糙度材质；漆面调成哑光（粗糙度约 0.55）并加一层低强度清漆参数 |
| 轮毂 | `car_wheel_*_car_body_*` | 同车身材质（共用贴图集），调成暗色金属 |
| 卡钳 | `car_brake_*` | 单独的牛血红 `#9E1C22` 材质 |
| 车窗 | `car_glass_*` | 深色玻璃，不透明，低粗糙度 |
| 轮胎 | `car_wheel_*_car_tire_*` | 保留原法线贴图，深灰橡胶，高粗糙度 |
| 尾灯 | （在贴图集上） | 脚本按颜色从贴图集挑出红橙色尾灯像素，生成自发光贴图 |
| 接触阴影 | `car_shadow_*` | 保留原烘焙阴影 |

- 删除 `clearcoat` 光泽壳，改用车身材质的清漆参数。
- 原设计中的红色腰线不做：原模型没有独立的腰线几何或材质。车上的红色由卡钳、尾灯和场景里扫过车身的红色光带体现。
- 车牌：贴图集上原有一张纽约州样式的车牌（「C08-LN」、「EMPIRE STATE」、「NEW YORK」及作者网址），在贴图集中左右镜像存放（约 x 620–922、y 290–490，以 4096×2048 计）。脚本把这块区域整体替换为一张不带州名的通用车牌：浅灰底、深色边框，只写「WE-456」，同样左右镜像绘制，使其在车上正向显示。
- 作者为这辆虚构车设计的「S」徽标保留。

- 署名文字（设置页「鸣谢」）：「Fictional supercar - V12 Goblin」作者 ollitei，来源链接，许可证 CC BY 4.0 链接，并注明「已修改：材质、配色和压缩」。

## 3. 场景和镜头

3D 画布挂在 `Layout` 最底层，铺满全屏，替换 `GarageBackdrop`。路由切换时不重建画布，只改变镜头、灯光和压暗程度，过渡时长约 1.2 秒，使用阻尼插值。

| 路由 | 镜头 | 灯光和效果 | 压暗 |
|---|---|---|---|
| `/` 车库 | 斜前方略高，车停在屏幕中上部 | 车在转台上自转，约 40 秒一圈；每约 6 秒一道红色光带扫过车身 | 0 |
| `/trial` 赛道试炼 | 压低到车侧 | 地面赛道线向后流动；车轮是独立部件时同步转动 | 0.45 |
| `/vault` 保险库 | 车尾 | 主光从牛血红渐变为香槟金 `#A8894F` | 0.35 |
| `/settings` 设置 | 同车库 | 不自转 | 0.2 |

「压暗」是叠在 3D 画面上的黑色遮罩不透明度，保证文字清晰。

- 拖动转车：只在车库页生效。手指在画面中部的车身区域横向拖动，转台跟手水平旋转，不能缩放或俯仰；松手后带惯性减速，2 秒后恢复自转。纵向滑动不拦截，页面照常滚动；车身区域以外的按钮和文字不受影响。
- 环境光：用 drei 的 Lightformer 在代码里生成摄影棚长条灯板，不下载 HDRI。地面是带微弱倒影的深色反射面。
- 后期效果：辉光、暗角、轻微胶片颗粒。试炼连击触发「氮气」时，短暂（约 0.6 秒）加入色散。
- 布局：画面以竖屏手机为主进行构图；横屏和桌面上相应拉远镜头，保证整辆车在画面内。

## 4. 加载、降级和性能

### 4.1 显示模式

`SceneHost` 根据以下条件决定显示模式，任一条件成立就只显示静帧，不加载 3D 分包：

1. 系统开启「减少动态效果」；
2. 浏览器不支持 WebGL 2；
3. 用户在设置里关闭了 3D；
4. 本次访问中 3D 已经失败过（加载失败、上下文丢失或帧率过低）。

### 4.2 加载顺序

1. 页面打开时立即显示当前路由对应镜头的静帧。
2. 界面渲染完成后，异步加载 3D 分包和 `car.glb`。
3. 车模型加载完成且第一帧渲染后，3D 画布在约 0.6 秒内从静帧上淡入；淡入完成后移除静帧。
4. 路由切换时，静帧模式下用约 0.4 秒交叉淡入换成新镜头的静帧。

### 4.3 帧率保护

- 设备像素比限制在 1 到 1.5 之间。
- 持续掉帧时，依次降低渲染分辨率、关闭后期效果；之后仍持续低于约 30 帧（约 5 秒），切换为静帧模式，本次访问不再尝试 3D。
- 页面不可见（切到其他标签页、锁屏）时暂停渲染。

### 4.4 静帧

- 三个镜头（车库、赛道、保险库）各一张竖屏 900×1600 和一张横屏 1600×900 的 WebP，共 6 张，放在 `public/stills/`，每张不超过 120 KB。设置页使用车库静帧。
- 页面按屏幕方向选用竖屏或横屏图，`object-fit: cover` 铺满。

### 4.5 设置

- 设置页新增「3D 车库」开关，默认开启，保存在本地（`localStorage`，与学习进度分开存放）。关闭后立即切换为静帧并释放 3D 资源；重新开启后再加载 3D。
- 设置页底部新增「鸣谢」，列出车模型署名，以及已有的第三方素材（ECDICT 词库、英文字体）。

## 6. 素材脚本

### 6.1 `npm run car`

1. 读取 `assets-src/car/` 下的 glTF（`.gltf` 或 `.glb`）。找不到时报错退出。
2. 打印模型里所有网格和材质的名称，供核对配置。
3. 把 Spec-Gloss 旧格式材质转换为标准金属度/粗糙度材质（three.js 不再支持旧格式）。
4. 按配置文件 `scripts/car.config.ts`（网格名规则 → 第 2 节的角色，外加要删除的网格）分配材质和参数；配置里的规则匹配不到任何网格，或有网格没有被任何规则覆盖，都报错退出。
5. 在车身贴图集上重绘车牌（见第 2 节）；从车身贴图集中挑出红橙色尾灯像素，生成自发光贴图挂到车身材质上。
6. 删除 `clearcoat` 光泽壳以及未使用的节点、材质、贴图和动画。四个车轮节点保持独立、旋转中心在轮轴上，并在节点上标记为车轮，供赛道页转动；其余网格按材质合并。网格用 meshopt 压缩；车身贴图集缩到 2048×1024，其余贴图缩到最长边 1024，全部转为 WebP。
7. 把车摆正：车头朝 +Z，车轮底部贴地（y = 0），整车居中，车长缩放到约 4.5 个单位。
8. 输出 `public/models/car.glb`；超过 3 MB 时报错退出且不覆盖已有文件。

### 6.2 `npm run stills`

1. 启动本地开发服务器，用 Playwright 的无头 Chromium 打开只在开发模式下存在的 `/__stills` 页面。
2. 依次以竖屏和横屏尺寸渲染车库、赛道、保险库三个镜头（不自转、光带停在固定位置、无颗粒，保证每次结果一致），截图后用 `sharp` 转为 WebP 写入 `public/stills/`。
3. 页面报错、模型加载失败、或截图几乎全黑时，脚本报错退出。
4. 第一次运行需要下载 Playwright 的 Chromium（约 150 MB）。

## 7. 错误处理

| 情况 | 处理 |
|---|---|
| 3D 分包或 `car.glb` 下载失败 | 留在静帧，不提示、不重试；下次打开页面再试 |
| WebGL 上下文丢失 | 切换为静帧，本次访问不再尝试 3D |
| 帧率持续过低 | 按 4.3 逐级降级，最终切换为静帧 |
| 静帧图片加载失败 | 显示深色径向渐变背景（与现在的背景相同），界面照常可用 |
| `npm run car` 找不到模型、材质配置不匹配、输出超过 3 MB | 报错退出并说明原因，不覆盖已有的 `car.glb` |
| `npm run stills` 页面报错或截图全黑 | 报错退出，不覆盖已有静帧 |

## 8. 测试

- **单元测试**：`mode.ts` 各条件组合；`poses.ts` 每个路由对应正确场景；拖动转车的角度和惯性计算（抽成纯函数）；偏好读写（含 `localStorage` 不可用时退回默认值）。
- **组件测试**（jsdom，无 WebGL）：`SceneHost` 在无 WebGL 2、减少动态效果、关闭 3D 时只显示静帧且不加载 3D 分包；条件满足时会加载分包（测试中替换为假模块），加载失败时停留在静帧；设置页的 3D 开关和「鸣谢」。
- **模型脚本测试**：用代码生成的小 glTF 样例跑材质替换、校验、摆正和体积上限逻辑。
- **真实渲染检查**：`npm run stills` 在真实 Chromium 里渲染三个镜头，兼作 3D 场景的冒烟测试。
- **手动验收**：手机上检查首页自转和拖动、三个页面的镜头过渡、关闭 3D 和减少动态效果时的静帧、构建产物中主程序包的压缩后大小。
