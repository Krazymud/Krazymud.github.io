# 青庐视觉重塑设计

日期：2026-10-14  
状态：待实现（设计已确认）

## 目标

把站点从「Midnight Garage」深夜 3D 车库，重塑为暖纸底、石墨素描 RX-7 FC、浅色 liquid glass 的轻量全站体验；去掉品牌 Midnight Garage，改用古风轻量中文命名。

成功标准：

- 首页不再加载 GLB / PBR / WebGL 车模与转盘；背景为预烘焙素描循环。
- 全站 UI 为暖纸 + 墨色 + 浅色毛玻璃；无红金双主题字标体系。
- 界面不再出现 Midnight Garage / PRIVATE VAULT 等旧品牌文案；导航为「日课 / 锦匣 / 案头」。
- 问候语与旧车库口吻脱钩，改为贴合青庐/暖纸墨色的中文表述。
- 旧音效资产全部停用；仅保留少量与新风格搭配的轻量反馈音。
- `prefers-reduced-motion: reduce` 时动画停在静帧，功能仍可用。

## 非目标

- 不在本设计中重绘最终成片（成片由对照实车照片手绘/板绘石墨素描后交付）。
- 不改日课（原试炼）算法、锦匣加密与同步、进度存档语义。
- 不保留 3D mods 改色转盘作为主路径（见「旧能力处置」）。
- 不做水墨写意车身（已否决）。

## 品牌与用词

| 角色 | 新文案 | 旧文案 |
|------|--------|--------|
| 站名 | 青庐 | Midnight Garage / MIDNIGHT GARAGE |
| 原试炼 | 日课 | 试炼 |
| 原保险库 | 锦匣 | 保险库 / PRIVATE VAULT |
| 原设置 | 案头 | 设置 |

路由 path（如 `/trial`、`/vault`、`/settings`）可保持不变，避免外链与书签断裂；**用户可见文案、`<title>`、导航、空状态、按钮**一律换新词。

包名、仓库名、localStorage key（如 `midnight-garage/progress`）若牵涉迁移成本，实现阶段单独评估：优先改用户可见层；存储 key 若保留须在实现计划中写明兼容策略，且 UI 不得再暴露旧站名。

## 视觉系统

### 色与材质

- **纸色底**：近 `#f7f4ec`–`#faf9f6` 的暖浅底，可有极轻纹理；去掉大面积 `#050506` 墨黑车库底作为默认。
- **墨色强调**：近黑石墨（正文、主按钮、描边），替代车库红 / 保险库金双 accent 主题。
- **Liquid glass**：半透明浅色面板、`backdrop-filter` 模糊、细高光边、大圆角；用于导航壳、卡片、表单、锦匣解锁与内容区。
- **字体**：去掉 Rajdhani 作为品牌展示字；正文继续系统栈（含 PingFang SC）；站名「青庐」可用衬线/宋体栈做轻古风，但不过度书法化。

### 全站范围

Layout、首页、日课、锦匣、案头及共用控件一并玻璃化与换色；旧 `data-theme='vault'` 红金切换删除或降为无品牌含义的中性变体（默认不需要第二套 accent）。

## 场景：石墨 RX-7 FC + 预烘焙动画

### 车与画风

- 车型结构对齐 **马自达 RX-7 FC**：隐藏式翻灯、楔形低趴、平直腰线、前后轮拱外扩、玻璃掀背、后期竖排三圆尾灯。
- 成片：**对照实车照片**手绘或板绘的**写实石墨素描**（体积、高光、板件），不是水墨少笔写意，也不是实时 3D。

### 动画

- 预烘焙短循环（建议 3–5s，WebP/APNG 或短视频择一，实现时按体积与透明通道选型）。
- 节拍：收灯静置 → 翻灯抬起 → 全开停顿 → 落下 → 回环。
- **触发**：进入首页后**自动循环**。
- **无障碍**：`prefers-reduced-motion: reduce` 时只显示静帧（收灯或全开择一，实现时固定一种并写进计划）。

### 技术置换

| 移除 / 降级 | 替代 |
|-------------|------|
| `car.glb` + 地板/墙 PBR 贴图主路径 | 素描成片 + 预烘焙循环资源 |
| 转盘拖拽旋转 | 无 |
| Bloom / AO / DoF / 环境反射等重后处理（车场景） | 无（画在成片里） |
| WebGL 不可用时的照片 still 回退 | 同一套素描静帧（无需两套叙事） |

首页 `SceneHost` / 3D `Stage` 主路径改为轻量媒体层（`<img>` / `<video>` / CSS 动画帧）；3D 代码可删除或移出首屏关键路径，实现计划里定迁移步骤。

## 旧能力处置

- **改装（Mods）转盘改色**：依赖 3D 材质，随车模主路径移除。实现时从首页拿掉入口；若需保留「忆旧」，另开设计，不在本次范围。
- **点火 intro / 3D 进站演出**：改为与素描循环协调的轻量入场（或直接显示循环），不要求保留旧点火时间轴。
- **音效（全部换新）**：
  - **不用**既有车库/引擎向资产（如 `ignition`、`rev`、`unlock` 等旧 mp3 与绑定逻辑中的「引擎」叙事）。
  - **改用**少量短、干净、偏纸木/轻触感的反馈音，与暖纸 + 石墨气质一致（例如：轻点、翻页感、匣锁轻响——具体采样在实现时选配或新制）。
  - 事件面尽量收束：导航/主按钮轻点、日课提交轻确认、锦匣开匣一次即可；避免长循环引擎声。
  - 静音开关行为保留；无音频或加载失败时静默失败，不挡主流程。

## 信息架构（用户可见）

- 顶栏/导航：青庐 · 日课 · 锦匣 · 案头。
- 首页问候（替换旧 `WELCOME BACK` / `HELLO, …`）：
  - 眉题：**又见**
  - 主标题：**{nickname}，安**（nickname 仍来自配置）
  - 「在一起第 N 天」若开启：改为 **相伴第 N 天**（数字逻辑不变）
  - 主 CTA / 次入口文案改为日课、锦匣语境（如「今日日课」「锦匣」），去掉一切 Midnight / START / 点火口吻。
- 锦匣：解锁与内容区用浅色玻璃；「PRIVATE VAULT」类英文眉题删除，解锁区标题用「锦匣」；开匣按钮文案改为中性短词（如「启封」），不用 START。

## 资产交付约定

实现可先用占位素描循环打通管道；**正式视觉**以交付的石墨成片为准：

- 至少：循环动画一份 + `prefers-reduced-motion` 静帧一份。
- 建议宽度覆盖桌面与手机（或一份大图 + CSS 裁切）。
- 授权与来源：写实写真仅作手绘参考，站点只发布手绘/板绘衍生稿。

## 测试要点

- 全站无「Midnight Garage」「PRIVATE VAULT」「WELCOME BACK」「HELLO,」等旧品牌/旧问候字符串（测试可 grep 用户可见文案）。
- 首页呈现「又见」与「{nickname}，安」；相伴天数文案正确（若配置开启）。
- 首页网络面板：无 `.glb` / 大块 PBR 纹理请求；有预烘焙媒体请求。
- 自动循环播放；reduced-motion 下为静帧。
- 日课 / 锦匣 / 案头导航文案正确；深链 path 仍可用。
- 旧音效文件名不再被请求；新反馈音在点击等路径可播，静音时不播。
- 锦匣解锁、读写、同步回归（行为不变，仅皮肤、文案与音效）。
