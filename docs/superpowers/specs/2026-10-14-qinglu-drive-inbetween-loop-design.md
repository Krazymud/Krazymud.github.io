# 青庐疾驰环：关键帧中间帧补齐设计

日期：2026-10-14  
状态：设计已确认（对话稿）；待规格文件审阅后进入实现计划  
基线：master 已合并蓝铅笔夜稿 + 关键帧 xfade 环（PR #41）  
父规格：`docs/superpowers/specs/2026-10-14-qinglu-bluepencil-drive-design.md`

## 1. 问题

线上 `fc-drive-loop` 由 6 张已批关键帧经 ffmpeg `xfade` 烘焙，观感是「几张图渐变」，未形成连贯疾驰循环动画。用户选择方向 **A：在关键帧之间补密集中间帧，重烘焙为帧序列环**。

## 2. 目标与非目标

### 目标

1. 首页循环从幻灯式 crossfade 升级为 **连贯帧序列动画**（约 8–12s、24fps）。  
2. 镜头路径不变：`K1 → K2 右入弯 → K3 漂移 → K3b 侧面 → K4 出弯 → K5≈K1`。  
3. 画风锁定蓝铅笔夜稿（线稿、排线、速度线、浅冷纸、车灯开）；不抄参考广告题材/商标。  
4. `fc-drive-still`、路由淡化、reduced-motion、夜稿 UI **行为不变**；仅替换 loop 成片与烘焙管线。

### 非目标

- 不重画已批关键帧 K1–K5（只读锚点）。  
- 不改日课 / 锦匣 / 进度语义；不回 3D。  
- 不做全片 AI 视频一镜生成（可控性差、难锁接环）。  
- 不要求光流自动插值作为主路径（可选辅修近邻帧）。

## 3. 中间帧策略

### 3.1 数量与分段

| 段 | 锚点 | 中间帧数 | 备注 |
|----|------|----------|------|
| A | K1→K2 | 3 | 直线 → 右入弯 |
| B | K2→K3 | 3 | 入弯 → 漂移 |
| C | K3→K3b | 4 | 大跳变绕镜，多补 |
| D | K3b→K4 | 4 | 侧面 → 出弯旋回 |
| E | K4→K5 | 3 | 出弯 → 接环位 |
| F | K5→K1 | 0–1 | 极短或跳过；K5≈K1 已锁接环 |

合计约 **20–25** 张中间帧 + 6 张关键帧。

### 3.2 生成约束

- 每张中间帧以 **相邻两端关键帧 + `styleboard.jpg`** 为风格/构图参考。  
- 必须：蓝/靛线、冷纸底、车灯开、无篮球/商标/文字水印。  
- 姿态与镜头应落在两端锚点之间的可读中间态（车身角度、道路、速度线方向连续推进）。  
- 文件落盘：`docs/superpowers/assets/2026-10-14-qinglu-drive-inbetweens/`  
  命名建议：`a01.jpg`… 或 `k01-k02-i1.jpg` 等可排序前缀；实现计划锁定最终命名表。

### 3.3 验收（中间帧）

- 逐段目视：相邻帧之间无「跳切感」主导；允许漫画式节拍，但不得再出现整段静止再硬切。  
- 任一段若中间帧失败（风格崩、车灯灭、题材污染），只重做该段，不整环推倒。

## 4. 烘焙

1. 更新 `scripts/bake-drive-loop.mjs`：输入 = 关键帧 + 中间帧有序列表；输出仍为  
   `public/sketch/fc-drive-loop.webm` + `.mp4`。  
2. 时序：短持帧（建议每姿态约 2–4 帧 @24fps）+ 相邻帧极短 dissolve（≤2–3 帧），总时长 **8–12s**。  
3. 分辨率：优先宽 1600；若体积过大可降至 ≤1280，保持画质可读。  
4. 接环：末帧落在 K5/K1 构图；HTML `<video loop>` 接环无明显跳变。  
5. 静帧 `fc-drive-still.webp` 仍来自 K1，本任务默认不改；仅当 loop 起点构图与 still 严重不一致时再重导出。

## 5. 运行时 / 产品行为

| 项 | 行为 |
|----|------|
| SketchStage / SceneHost | 不改契约：`ROUTE_FADE_MS=300`、home loop / inner still |
| 资产路径 | 仍为 `fc-drive-loop.*` / `fc-drive-still.webp`（同名替换） |
| reduced-motion | 仍仅静帧 |
| 加载失败 | 仍静帧兜底 |

## 6. 测试与发布

- 自动化：`npx vitest run`、`npx tsc -b` 保持绿；scene 断言路径不变。  
- 手测：首页连贯疾驰感；`/trial` 等仍静帧；接环；无商标。  
- 合并 `master` 后走现有 GitHub Pages Deploy；**仅在用户要求时部署**。

## 7. 成功标准

- 去掉顶栏后，第一屏仍是「青庐」+ 蓝铅笔疾驰 FC，且背景是 **运动中的环**，不是幻灯渐变。  
- 时长 8–12s；K5→K1 接环可接受。  
- 夜稿 UI 与路由淡化无回归。

## 8. 已确认决策

| 项 | 选择 |
|----|------|
| 方向 | A：密集中间帧 + 帧序列烘焙 |
| 关键帧 | 只读，不重画 |
| 中间帧密度 | 段间 3–4 张；绕镜段 4 张 |
| 环长 | 仍 8–12s |
| UI / 路由 | 不变，只换 loop 媒体 |
